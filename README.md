# Sample Page

A minimal React page for manual testing with a counter, text input, and toggle.

## Setup

```bash
pnpm install
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## What's included

- **Counter** — increment, decrement, and reset
- **Greeting** — text input with live echo
- **Toggle** — simple dark background switch

Built with Vite, React, TypeScript, Tailwind CSS, and shadcn-style UI components.
